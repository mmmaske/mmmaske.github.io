Homelab Behind CGNAT

CGNAT workarounds, Tailscale, Cloudflare Tunnel

Goal

Run useful Internet-accessible services from home without a VPS. ISP uses CGNAT — traditional inbound port forwarding unavailable.

Experiment

Cloudflare Tunnel for public access, Tailscale for private/admin services, DNS management, container networking.

What Broke

Origin certificate validation, container hostname vs IP addressing, public share link behavior.

Fix

Proper TLS termination, Tailscale for LAN access, segregated public/private boundary.

Lessons

CGNAT workarounds, zero-trust-ish access patterns, private/public service separation, multi-host architecture.

Home Assistant / MQTT Automation

Custom integrations, media control, smart lighting

Goal

Build more than a stock Home Assistant installation — custom integration scripts, MQTT as general-purpose messaging layer.

Experiment

Workstation media control bridge: Home Assistant ↔ MQTT ↔ browser media playback via MPRIS/playerctl. Custom lighting behavior (red → purple → blue → purple → red cycle).

What Broke

MPRIS integration quirks, browser media API inconsistencies, MQTT topic structure design.

Fix

Custom Node.js bridge scripts, structured MQTT topics, proper async messaging patterns.

Lessons

MQTT as a general-purpose messaging layer works well. Custom integrations require careful topic design and error handling.

Multi-Host Docker Management

Dockhand + Hawser — two Docker hosts, one environment

Goal

Manage ~32 containers on `not-a-server` and ~13 containers on `not-a-workstation` as one personal infrastructure environment.

Experiment

Dockhand on `not-a-server` connecting to `not-a-workstation` via Hawser Standard over LAN. Remote Docker administration, multi-machine orchestration.

What Broke

LAN connectivity issues, authentication between management components, container networking across hosts.

Fix

Proper Docker socket configuration, Hawser authentication setup, network segmentation.

Lessons

Multi-host Docker is manageable with the right tooling. Remote administration needs secure auth and clear network boundaries.

Containerized Onion Service

Tor in Docker, SOCKS5 proxy experimentation

Goal

Host an onion site in an isolated container. Read generated onion hostname, use Tor container as SOCKS5 proxy, understand Tor relays and exit nodes.

Experiment

`onion-tor` container rather than system-wide Tor installation. Isolated deployment, SOCKS5 proxy configuration.

What Broke

Container hostname resolution, proxy routing, Tor circuit stability.

Fix

Proper container networking, SOCKS5 proxy configuration, isolated deployment patterns.

Lessons

Containerized Tor is surprisingly straightforward. Privacy-network concepts are valuable even if rarely used in production.

ownCloud Infinite Scale

Personal cloud behind CGNAT with public + private access

Goal

Expose ownCloud Infinite Scale through a public domain while preserving private/LAN access. Troubleshoot origin protocol/certificate behavior.

Experiment

Public access through Cloudflare, Tailscale for private access, HTTPS vs HTTP origin behavior, WebDAV, public share links.

What Broke

Origin certificate validation, container hostname vs IP addressing, public share link recreation.

Fix

Proper TLS termination, correct origin configuration, WebDAV path handling.

Lessons

Running a personal cloud behind CGNAT is a full-stack networking problem. TLS and origin behavior are the hardest parts.
