I wanted to control my workstation media with homeassistant. Here's what happened.

October 17, 2026

MQTT as a media controller, with a small bridge application to publish to topics.

Problem

My workstation is hooked up to speakers around the house, but no way to control media remotely.

What I Tried

Back when I was on windows, I used HASS which fulfilled my needs. Now that I’m on linux, the out-of-the-box solutions didn’t play well with my custom desktop environment setup.

What Broke

MPRIS integration quirks, browser media API inconsistencies, MQTT topic structure design.

Fix

Built a custom Node.js bridge script that published playerctl output into structured MQTT topics that handles proper async messaging patterns.

What I Learned

MQTT as a general-purpose messaging layer works well for realtime event handling. Volume controls were handled by wpctl while playerctl fetched media metadata from the OS. Custom integrations require careful topic design and error handling.
